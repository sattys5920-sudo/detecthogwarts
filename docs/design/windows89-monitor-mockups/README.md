# Windows '89 모니터 바탕화면 시안

1989년식 CRT 모니터로 보는 것 같은 느낌의 바탕화면 아이콘 프로토타입.

- `Desktop.dc.html` — 바탕화면 아이콘 (프로필 · moi.net · 검색 · 내 폴더 · 인터넷, 하단에 시작 표시줄). **클릭 가능한 프로토타입**: 아이콘을 누르면 해당 화면이 열리고, 타이틀바의 ✕를 누르면 바탕화면으로 돌아갑니다.
  - `moi.net`(채팅)은 실제로 동작합니다: 입력창에 메시지를 쓰고 Enter나 "보내기"를 누르면 내 메시지가 프로필 아바타("나")와 함께 즉시 대화창에 추가되고, 상대방 메시지는 프로필 아이콘과 함께 표시됩니다.
- `canvas.json` — 캔버스 레이아웃 (단일 아트보드, 포커스 뷰로 바로 열림)

Claude Design 캔버스로 발행한 시안: https://claude.ai/code/artifact/7cfb09ab-052e-4039-a923-6d5232c78d5d

베이지색 플라스틱 CRT 본체, 스캔라인, 비네트 효과의 모니터 프레임 안에 청록색 클래식 데스크톱 화면을 담았습니다.
