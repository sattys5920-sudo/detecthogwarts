# 탐사 활동 — 인터랙티브 NPC 대화 시스템 (다음 단계 설계 메모)

아직 구현 전. `docs/story.md`의 6명 용의자 + 피해자를 다루는 다음 개발 단계를 위한 메모.

## 요구사항 (요청 원문)

모든 조사는 인터랙티브로 진행. 특정 용의자/NPC를 눌러서 대화 진행 가능. 대화에 따라 플레이어가 원하는 답변/행동을 인터랙티브하게 선택하면 그에 맞는 결과가 나옴.

## 제안 구조

- `src/data/npcs.ts`: NPC 목록(용의자 6명 + 관련 인물), 초상/아이콘, 소개.
- `src/data/dialogue/<npcId>.ts`: 각 NPC별 대화 트리 — 노드 `{ id, npcLine, options: [{ text, next, effect? }] }` 형태. `effect`로 조사수첩 등록(`useNotebook().register`)이나 스탯 변화를 트리거.
- 분기는 DAY 1~5 진행 상태(`src/context/GameContext`에 `currentDay` 추가 필요)에 따라 잠금/해금.
- 같은 단서를 여러 대화 경로로 얻을 수 있도록 각 NPC 트리에 최소 2개 이상의 진입 경로 설계 (요청사항: "잘못된 선택으로 핵심 스토리가 막히면 안 됨").
- ExplorationPage를 NPC 목록 → 대화 화면 2단 구조로 재작성.

## 다음에 필요한 결정

- DAY 진행을 실시간(달력 기준)으로 할지, 관리자가 수동으로 다음 날을 여는 방식으로 할지.
- 용의자 5번 및 일부 [미정] 설정이 확정되면 해당 NPC 대화 트리 작성 가능.
